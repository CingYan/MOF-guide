# 天空之城 Online 攻略資料庫

Master of Fantasy（台服譯名「天空之城 Online」）的非官方玩家攻略站。

## 這站解決什麼問題

原始資料來源是 [Master of Fantasy Wiki](https://master-of-fantasy.fandom.com)，但：

- **全站是印尼文**
- 資料散在 567 個頁面，查一把武器要一頁一頁翻
- 表格是靜態 HTML，**不能排序、不能篩選、不能跨頁搜尋**
- 沒有掉落物反查（只能從怪物找道具，不能從道具找怪物）

這站把整個 wiki 重新結構化成可查詢的資料庫，介面為繁體中文。

## 功能

| 頁面 | 內容 |
|---|---|
| 職業 | 4 職業轉職樹、可用武器、技能總覽 |
| 技能 | 154 個技能，展開看 I～X 各階傷害／冷卻／MP／需求等級 |
| 武器 | 425 把，可依職業／類型／稀有度／屬性／等級篩選，傷害排序 |
| 防具飾品 | 428 件防具（含 28 面盾）＋ 162 件飾品 |
| 怪物圖鑑 | 238 隻，含等級／HP／屬性／出沒地／完整掉落表 |
| **掉落物反查** | 1,526 種道具 → 反查掉落來源（**wiki 沒有這功能**） |
| **屬性相剋** | 武器 × 怪物屬性矩陣，附「打這種怪帶什麼」反查 |
| 遊戲系統 | 強化石、製作（541 列）、藥水、狀態異常、轉職考試等 |
| 寵物 | 8 隻 Lv.1～10 加成對照 |
| NPC 任務 | 64 位 NPC 與任務等級／目標／獎勵 |
| **任務規劃** | 依共用討伐怪物／蒐集品集中任務，顯示合計數量、NPC、前置任務與本機完成狀態 |

全站頂部搜尋可跨所有類別即時查詢。

## 資料誠實說明

- **數值來自社群 wiki，可能與你所在伺服器版本有落差**，以遊戲內為準。
- 238 隻怪物中有 151 隻 **wiki 未記錄 HP**，站上顯示「—」，不是解析錯誤。
- 說明文字保留 wiki 原文（印尼文）；**介面標籤、欄位名、分類已翻成繁中**。整段敘述沒有翻譯。
- 屬性相剋表是把 wiki 的散文敘述手工結構化，**wiki 未提供實際加成百分比**。
- 轉職樹依 wiki 各職業頁的 1～5 轉資料整理。

## 技術

純靜態站，無框架、無建置工具、無外部相依。

```
docs/
  index.html   外殼
  app.js       SPA（hash routing、延遲載入、篩選排序）
  style.css    深色主題、響應式
  data/*.json  結構化資料（按區塊分檔）
  img/         1,310 張圖示（本機化，不 hotlink）
build/
  fetch.py     抓取 wiki 全站條目
  parse.py     wikitext → 結構化 JSON
  systems.py   系統／道具頁 + 屬性矩陣
  split.py     切分區檔 + 全站搜尋索引
```

## 重建資料

```bash
python3 build/fetch.py    # 重抓 wiki（會覆寫 data/raw.json）
python3 build/parse.py    # 解析主資料 -> docs/data/mof.json
python3 build/systems.py  # 解析系統頁 + 屬性矩陣
python3 build/split.py    # 切分區檔 + 建搜尋索引
```

## 本機預覽

```bash
cd docs && python3 -m http.server 8787
# 開 http://127.0.0.1:8787
```
